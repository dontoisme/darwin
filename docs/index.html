Features

🎯

Smart Capture

Only screenshot screens affected by your code changes. No wasted CI time on unchanged UI.

🔍

Pixel-Level Diff

ImageMagick-powered comparison catches even subtle visual regressions with HTML reports.

📊

Visual Timeline

Interactive viewer with timeline playback and group filtering. Watch your app evolve commit-by-commit.

🗺️

App Flow Map

Visualize screen connections and navigation paths. See your app's architecture at a glance.

🔗

Git Hooks

Auto-capture or prompt after commits with Swift changes. Seamless git workflow integration.

⚡

CI-Ready

Works with any CI system. Generate diff reports for PR reviews automatically.

Commands

darwin init

darwin capture

darwin diff

darwin viewer

darwin status

Show state and pending changes

darwin hook install

Auto-capture on commits

How It Works

1

Manifest maps source to screens

Define which Swift files affect which UI screens in manifest.json

2

Git diff detects changes

Darwin checks which files changed since your last capture

3

XCUITest captures affected screens

Only the screens that could have changed are re-captured

4

Explore in the viewer

Browse captures, compare changes, watch the timelapse, explore the map

Quick Start

Terminal
# Initialize in your iOS project
darwin init

# Capture baseline screenshots
darwin capture --baseline

# Make changes, then smart capture
darwin capture

# Open the visual timeline
darwin viewer

# Optional: auto-capture on commits
darwin hook install

Use Cases

Visual regression testing — Catch unintended UI changes before they ship
Design review — Generate visual diffs for PR reviews
AI-assisted development — Track changes made by AI coding assistants
Documentation — Build a visual history of your app's evolution
