Capabilities

Built for AI-assisted development

Smart Capture

Only screenshot screens affected by your code changes. Darwin auto-detects new views and updates its manifest—no manual config maintenance.

Pixel-Level Diff

ImageMagick-powered comparison catches even subtle visual regressions with HTML reports.

AI-Aware Diffing Soon

Structured diff reports your AI can review. Close the loop—let the same assistant that wrote the code verify the visual result.

Visual Timeline

Interactive viewer with timeline playback and group filtering. Watch your app evolve commit-by-commit.

App Flow Map

Visualize screen connections and navigation paths. See your app's architecture at a glance.

Git Hooks

Auto-capture or prompt after commits with Swift changes. Seamless git workflow integration.

Process

How Darwin works

1

Manifest maps source to screens

Darwin tracks which Swift files affect which UI screens in manifest.json—auto-updated as you add views.

2

Git diff detects changes

When you commit, Darwin checks which files changed since the last capture.

3

XCUITest captures affected screens

Only screens that could have changed are re-captured. No wasted CI time.

4

Review what changed

Browse in the viewer, or feed structured diffs to your AI for automated review.

CLI

Commands

darwin init Initialize in your iOS project
darwin capture Smart capture changed screens
darwin diff Compare between captures
darwin viewer Open interactive timeline
darwin status Show state and pending changes
darwin hook install Auto-capture on commits
