## Quick Start Section

### Get Started in 60 Seconds

**Step 1: Install**
```
brew tap dontoisme/darwin && brew install darwin
```

**Step 2: Paste into Claude Code or Cursor**
```
Set up Darwin for visual regression testing.
Run: darwin init --ai-interactive
Present the options to me, then complete the setup
including test navigation logic.
Finally, run: darwin capture --baseline
```

**Step 3: There is no step 3**
Your AI assistant handles everything—detecting screens, writing tests, capturing screenshots.

## "How It Works" Section

1. **You paste, AI executes**
   Darwin outputs structured prompts your AI assistant understands.

2. **AI analyzes your codebase**
   Finds SwiftUI screens, maps navigation flows, writes test logic.

3. **Screenshots happen automatically**
   After every commit, Darwin captures only what changed.

4. **You see the evolution**
   Interactive timeline shows your app's visual history.
